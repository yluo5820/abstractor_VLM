# VLM project research

Start with [the project report](research/deliverables/vlm_project_report.md), or read the [PDF](output/pdf/vlm_project_ideas.pdf).

The report ranks seven ideas for a compute-constrained class project and develops five in detail. Its preferred pilot tests whether visual-token compression preserves object identity while losing spatial relationships. It includes nearest prior work, baselines, datasets, planning budgets, pilot gates, and publication risks.

Evidence coverage in the original research report is explicitly tiered: 1,220 title/category records, plus 65 distinct papers inspected beyond that screen; 36 included selected full-text section reads. This is not 1,000 full-paper reviews. No experiments were run for that September 14 report.

The subsequent [PACE ICE benchmark workflow](benchmarks/README.md) contains real LFM2.5 visual-reasoning experiments. See [the first accessible-data results](benchmarks/reports/first-pass.md) and [verified connection/allocation commands](benchmarks/docs/VERIFIED_ICE.md).
