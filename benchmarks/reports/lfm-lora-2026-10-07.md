## First trial setup

- Original official train split: 9,000 training and 1,000 fixed held-out validation questions; split seed 20261007.
- Same composite presentation, native image processor and prompt as the zero-shot evaluation. Supervise only the answer and end-of-answer tokens.
- Freeze all original weights, including vision encoder and projector. Language-layer LoRA: rank 16, alpha 32, dropout 0.05. BF16 base, FP32 adapters, no quantization.
- AdamW, learning rate 1e-4 with 20-update warm-up, weight decay 0.01, gradient clipping 1.0; microbatch 1 and effective batch 16.
- Use the job's time budget with **no independent epoch cutoff**. Reserve time for validation and checkpointing. Select by accuracy on the same 128 validation IDs, breaking ties by loss; retain the unmodified model if no adapter is better.
- Report actual examples/epochs and validation coverage. The remaining validation questions provide a broader development score; the test set is not touched during selection. A subsequent test evaluation must load the selected adapter and retain the existing test manifest and scoring protocol.

The two-hour allocation includes training, periodic validation and saving. It does not include a separately scheduled full test evaluation. No fine-tuned benchmark accuracy is available yet.
